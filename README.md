# 💰 Personal Finance Tracker

A user-friendly platform for managing personal finances by tracking expenses, setting budgets, and analyzing spending patterns.

## ✨ Features

- ➕ Add, edit, and delete expenses
- 🏷️ Categorize and filter transactions
- 🔍 Search and view past transactions
- 🎯 Set budgets and monitor progress
- 📊 Visualize financial data with charts and graphs

## 🧠 Object-Oriented Design Principles

- **Encapsulation**  
  Classes like `Expense`, `User`, and `Budget` encapsulate data and related behaviors, ensuring clean interfaces and data integrity.

- **Abstraction**  
  Users interact with high-level features like adding expenses or viewing reports, while the app handles the internal complexity under the hood.

- **Polymorphism**  
  Actions like editing/deleting expenses or switching between different chart types (bar, pie, heatmap) are implemented using polymorphic behavior.
